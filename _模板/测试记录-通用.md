# AI 安全测试通用记录模板

适用于明确授权的实验、靶场和回归测试。主题笔记只需补充该攻击面特有的字段。

## 通用记录

```text
测试编号：
测试日期与时间：
测试人员：
授权范围与批准人：

目标系统 / 组件：
环境：本地 / 靶场 / 测试 / 预生产
目标版本 / 模型版本 / Prompt 版本：
测试账户、角色与租户：
关联工单 / 运行 ID / 会话 ID：

测试目的：
前置条件：
输入或测试动作：
预期安全行为：
实际结果：

风险等级：低 / 中 / 高 / 待确认
判定依据：
根因假设：

证据文件及哈希：
日志时间范围：
截图 / 请求 / 响应 / 指标位置：

清理动作：
修复建议：
复测结果：
遗留问题：
```

## 最小安全约束

- 使用合成、脱敏或专门准备的数据。
- 不触达真实用户、生产凭据和未授权下游系统。
- 事先定义停止条件、资源预算和清理步骤。
- 记录模型、数据、代码、依赖和配置版本。
- 成功判定必须基于可复核证据，不能只依据模型文字回答。
