## 使用约定

1. 新笔记先按 [_规范/元数据规范.md](_规范/元数据规范.md) 填写 Front Matter。
2. 新笔记必须加入至少一个领域索引和一个跨主题索引。
3. 概念、实验、测试清单和复习材料尽量分离；超过约 1200 行时优先评估拆分。
4. 通用记录字段引用公共模板，主题笔记只维护专用字段和判定规则。
5. 所有攻击测试只在明确授权、隔离和可回滚的环境中进行。
