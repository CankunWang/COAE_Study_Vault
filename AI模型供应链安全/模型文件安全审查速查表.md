# 模型文件安全审查速查表

> 适用于 `.pt`、`.pth`、`.bin`、Pickle 和其他第三方模型产物。仅在自有或授权环境使用。

## 1. 红线

```text
不在办公机、生产机或高权限主机直接加载未知模型
不对未知文件使用 pickle.load / torch.load(weights_only=False)
不因为加载报错就批量放行所有自定义类型
不依赖扩展名、总体准确率或单一扫描结果判断安全
```

## 2. 三类风险不要混淆

| 风险 | 问题 | 主要控制 |
|---|---|---|
| 不安全反序列化 | 加载时是否执行行为 | 非可执行格式、`weights_only=True`、隔离 |
| 张量隐写/参数篡改 | 权重中是否藏数据或被微调 | 签名、摘要、张量对比、统计分析 |
| 模型后门 | 特定输入是否触发异常行为 | 行为评估、触发测试、分组指标 |

## 3. 快速决策树

```text
来源是否明确且可验证？
├─ 否 → 隔离，不进入部署
└─ 是
   ↓
签名或可信 SHA-256 是否匹配？
├─ 否 → 拒绝并调查
└─ 是
   ↓
是否需要 Pickle/任意 Python 对象恢复？
├─ 是 → 能否改为 state_dict 或非可执行格式？
│       ├─ 能 → 转换并重新审批
│       └─ 不能 → 仅在严格隔离环境、完全可信时审查
└─ 否
   ↓
参数 key / shape / dtype / numel 是否符合清单？
├─ 否 → 拒绝并调查
└─ 是
   ↓
安全测试和行为评估是否通过？
├─ 否 → 不部署
└─ 是 → 注册、固定摘要、批准后部署
```

## 8. 张量隐写检查

有可信基线：

```text
[ ] 比较文件 SHA-256
[ ] 比较每个张量摘要
[ ] 比较逐元素相等性
[ ] 统计最大绝对/相对误差
[ ] 分析 ULP 与低位差异分布
[ ] 比较固定集逐样本输出
```

无可信基线：

```text
[ ] 检查各层 LSB 的 0/1 比例
[ ] 检查位平面熵、周期和相关性
[ ] 查找跨参数重复结构或标记
[ ] 对照训练、量化、转换流程解释异常
[ ] 将统计异常视为线索，不直接定罪
```

## 9. Float32 速记

```text
Float32 = 1 位符号 + 8 位指数 + 23 位尾数
```

\[
x=(-1)^s(1.m)2^{E_{\text{stored}}-127}
\]

普通规格化数翻转尾数第 \(k\) 位（最低位 \(k=0\)）：

\[
\Delta_k=2^{E-23+k}
\]

`0.15625`：

```text
0.15625 = 0.00101₂ = 1.01₂ × 2⁻³
bits = 0 | 01111100 | 01000000000000000000000
```

| 翻转 | 变化 |
|---|---:|
| 尾数 Bit 0 | 约 \(1.49\times10^{-8}\) |
| 尾数 Bit 22 | \(0.0625\) |

## 10. 部署门禁

```text
[ ] 仅从批准的不可变注册表拉取
[ ] 生产端重新验证签名和摘要
[ ] 模型、代码、依赖和配置版本绑定
[ ] 加载进程低权限
[ ] 默认限制出站网络和子进程
[ ] 不向模型服务暴露长期凭据
[ ] 记录模型摘要、审批人和加载参数
[ ] 有已验证的回滚版本
```

## 11. 组合攻击链速查

```text
最终代码 → UTF-8 bytes → 加 4-byte 长度
    → 每个 Float32 写入 2 LSB
    → 修改后的张量放回 state_dict
    → Wrapper 内嵌 state_dict + key + LSB 参数
    → __reduce__ 返回危险 callable
    → 非受限加载执行 Loader
    → Loader 提取张量低位
    → 再次执行最终内容
```

关键边界：

| 阶段 | 风险 | 检测/阻断 |
|---|---|---|
| 外层 Pickle | `__reduce__` 触发 callable | `weights_only=True`、非可执行格式 |
| 内嵌对象 | 嵌套 `pickle.loads` | 类型门禁、静态审查 |
| 张量低位 | 隐藏最终字节 | 签名、摘要、ULP/位平面比较 |
| 最终执行 | `exec`、Shell、子进程 | 低权限、断网、进程策略 |

容量公式：

\[
N=\left\lceil\frac{8(L+4)}{b}\right\rceil
\]

其中 \(L\) 是载荷字节数，\(b\) 是每元素使用的 LSB 数。若 \(b=2\)：

\[
N=4(L+4)
\]

## 12. 组合攻击排查信号

```text
[ ] 顶层对象不是普通 dict / state_dict
[ ] 文件中存在异常长代码字符串或嵌套 Pickle
[ ] 出现 exec、pickle.loads 或未知 globals
[ ] 模型加载后返回 None 或类型异常
[ ] 加载期间启动 sh/bash/cmd/powershell
[ ] 加载期间出现未知出站 TCP
[ ] 进程在加载后突然退出或进入重启循环
[ ] 某一大层集中出现 1–2 ULP 差异
[ ] 低位分布与可信版本明显不同
[ ] 文件大小和普通 checkpoint 不相称
```

事件优先级：

```text
模型加载 + Shell 子进程 + 未知出站连接
    → 高优先级隔离与响应

摘要不匹配但没有运行迹象
    → 禁止部署，调查供应链

仅低位统计异常且无可信基线
    → 保留证据，进一步复核，不能直接定罪
```

## 13. 防御验证用例

```text
[ ] 无害未知类被 weights_only=True 拒绝
[ ] 外部输入无法到达 weights_only=False
[ ] 顶层类型、key、shape、dtype 不符时安全停止
[ ] 单个测试低位变化能被摘要门禁发现
[ ] 加载进程默认无出站网络
[ ] 模型进程无法启动 Shell
[ ] 异常长度和 shape 不会耗尽宿主资源
[ ] 加载失败不会进入无限重启
```

不要用真实反向 Shell 验证这些控制。
